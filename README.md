# REST API - Ejemplo en PHP

Este proyecto implementa una API REST básica usando PHP que devuelve un saludo.

## **Requisitos**

- PHP 7.4+
- Servidor web integrado de PHP

## **Instrucciones**

1. Guarda el código en un archivo `index.php`.

2. Ejecuta el servidor integrado de PHP:
   ```bash
   php -S localhost:3000
